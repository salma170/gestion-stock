#description 

-Vous formez une petite équipe de développement. Vous devez livrer Stock, une application PHP en
ligne de commande qui gère le stock d’un magasin (produits, quantités, valeur du stock,
commandes), en appliquant la POO PHP. Le travail est réparti par classes sur un seul dépôt GitHub
(tout le monde travaille sur main, sans branches), et chaque push déclenche automatiquement une
chaîne d’intégration continue avec GitHub Actions, comme vu en cours.
